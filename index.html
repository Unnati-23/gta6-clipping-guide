Learn clipping before GTA 6 drops

GTA 6 releases on November 19th. Every big streamer will play it for hours, and someone has to turn those streams into short, viral clips. People get paid to do that. Here's exactly how to start for free: the tools, the websites, and every step in between.

What is clipping?

You take a long video, usually a stream, podcast or interview, and cut out the best 15–60 second moments. You turn them vertical (9:16), add captions, and post them on TikTok, Instagram Reels or YouTube Shorts. Brands and streamers pay clippers for the views those clips get, or hire clippers directly to run their short-form content.

Step 01

Get footage you're allowed to clip

This is the step most beginners skip, and it's the reason clips get rejected or taken down. Only clip footage you have permission to reuse.

  1. Easiest: use a campaign's footage

    Every clipping campaign (more on these in Step 04) tells you exactly which videos or streams to clip. Some give you a folder of footage; some name the channel. If you join a campaign first, the permission part is handled.

  2. Or: work for a streamer directly

    If a streamer hires you, they're giving you permission. Get it in writing, even if it's just a DM.

  3. Copy the video link

    On YouTube, open the stream or video and copy the link from the address bar or the Share button. All three tools below take a YouTube link or a video file you've downloaded.

  4. Practise on anything for now

    You don't need GTA 6 to learn this. Practise on any long gaming stream or podcast you're allowed to use, and keep those practice clips private until you have permission to post them.

Chopify

Free local AI clipper for Shorts, Reels and TikTok, with a browser dashboard.

  • Paste a video file or a YouTube link and click Find clips
  • Listens and watches for reactions, laughs, impacts and gameplay moments, so it works for streams with little talking
  • 13 caption styles, an editor to fix words, MP4 + subtitle (SRT) export
  • No account, no API key, no uploads to the cloud

How to install it

  1. Open PowerShell (Windows) or Terminal (Mac/Linux).
  2. Paste the command for your computer and press Enter. It checks for Git, Python 3.11+ and FFmpeg, installs what's missing, downloads Chopify and opens it in your browser.
irm https://raw.githubusercontent.com/mehbul/chopify/main/install.ps1 | iex
curl -fsSL https://raw.githubusercontent.com/mehbul/chopify/main/install.sh | bash

Want to see what the command does before you run it? The installer files are short and commented on the GitHub page.

How to use it

  1. Chopify Studio opens at http://127.0.0.1:8765 in your browser.
  2. Paste the video link or file path and click Find clips. Add several links on separate lines to queue them.
  3. Review the suggested clips, fix any caption mistakes, and pick a look in Caption Studio.
  4. Export as 9:16 and download your clips.

If YouTube links don't download on Windows, install Deno (winget install DenoLand.Deno) and restart your terminal.

AutoClip

"One link, one click." Paste a link, choose your platform, and get finished clips with covers and captions you can post.

  • Makes up to 10 clips per platform, ranked by score, with extra options you can generate on demand
  • Formats for TikTok, Reels and YouTube Shorts automatically
  • Each clip comes with a cover, title, description and hashtags
  • Editing and rendering happen on your computer. The app is free; if you use a cloud AI model, that model charges a small amount per use

How to install it

  1. Go to the Releases page (button below).
  2. Download the right file. Mac with Apple Silicon (M1/M2/M3/M4): the .dmg. Windows 10/11: the -setup.exe. Python and FFmpeg come bundled.
  3. Install it and open it like any other app.

Intel Mac or Linux? There's no desktop installer yet. Use the Docker or CLI version from the GitHub page instead.

How to use it

  1. Try the example first. On the home screen, open the built-in example project. It needs no API key, so you can see what it makes.
  2. Set up a model. In Settings, choose an AI provider, paste its API key, test the connection and save. Or run a free local model with Ollama or LM Studio instead.
  3. Paste your link. Choose TikTok, Reels or YouTube Shorts and let it generate.
  4. Check, then download. Preview each clip, check the captions and framing, and download the publish pack.

OpenShorts

The open-source alternative to OpusClip. Turns long videos into 9:16 clips for Shorts, TikTok and Reels.

  • Picks 3–15 moments of 15–60 seconds, each with a virality score and titles for every platform
  • Face tracking keeps the streamer in frame; two people on camera get stacked
  • Auto captions, an editable hook line at the start, and a full clip editor
  • Self-hosted is free forever, with no watermark and no limits

How to install it

  1. Install Docker Desktop and open it. You need 8GB+ of RAM.
  2. Get a free Google Gemini API key. It powers the moment-picking. (Prefer fully local? It also works with Ollama or LM Studio.)
  3. Open Terminal and run these, one after the other:
git clone https://github.com/mutonby/openshorts.git
cd openshorts
docker compose up --build

The first build downloads a lot, so give it a while.

How to use it

  1. Open http://localhost:5175 in your browser.
  2. Go to Settings and paste your Gemini key. You only need the other keys for extras like dubbing and auto-posting.
  3. Open Clip Generator, paste a YouTube link or upload a file, and wait. On a normal computer an 8-minute video takes about 5–8 minutes.
  4. Open any clip in the editor to trim words, change framing or edit the hook, then download.
Don't want to install anything? openshorts.app is the same software online. The free plan clips your first video (up to 60 minutes), then 20 minutes a month, with a watermark. Paid plans start at $12/month.

Step 03

Make it a clip people finish

The AI finds the moments. You decide which ones are worth posting. Check every clip before it goes up.

  1. Hook in the first 2 seconds

    Start on the reaction, the crash, the line. Cut the slow lead-up.

  2. Make it make sense alone

    Someone scrolling has no context. If they need the last 10 minutes to get it, skip that clip.

  3. Captions on, always

    Most people scroll on mute. All three tools burn captions in; fix any wrong words first.

  4. Follow the campaign brief exactly

    Some campaigns require a disclosure at the start, certain hashtags or tags, or a specific length. Don't cut a moment so it changes what the streamer meant.

  5. Post from your own account

    Use a TikTok, Instagram, YouTube or X account you control. Making a separate account just for gaming clips keeps your feed and stats clean.

Step 04 · The money

3 places to get paid for clips

Option 1: join paid clipping campaigns, where you get paid for the views your clips get. These three work together: Content Rewards lists the campaigns, Whop handles your account and payouts, and Amplify Media is a clipping agency whose campaigns run through them. Option 2 (pitching streamers directly) is further down.

Content Rewards

A marketplace of clipping campaigns. Brands, creators and streamers fund a campaign, and you're paid for the views your clips get.

How to join and get paid

  1. Sign up as a creator on Content Rewards. It runs on Whop, so you'll use a Whop account.
  2. Connect the account you'll post from: TikTok, Instagram, YouTube, X or Facebook.
  3. Open Discover and compare campaigns. Each one shows the rate per 1,000 views, the minimum payout, the maximum per clip, which platforms count, and how much budget is left. Look for gaming and streamer campaigns.
  4. Join or apply. Some campaigns accept you straight away; others review you first. Open campaigns have no follower minimum.
  5. Read the brief and rules: which footage to use, length, hashtags, disclosure.
  6. Post your clip, then submit its link within 30 minutes of posting.
  7. Wait for review. The campaign's own team approves or rejects it against the brief.
  8. Get paid. Payouts run about every 10 days (7 days of earning plus a 3-day hold), for up to 30 days after you submit. Content Rewards takes a 10% creator fee. Money moves to your Whop Balance, and you withdraw from there.

Typical streamer campaigns pay roughly $0.75–$1 per 1,000 views, and some gaming campaigns pay more. Rates change all the time, so always check the live listing.

Whop

The platform Content Rewards runs on. It's where your money lands, and where clipping agencies and communities live.

How to set it up

  1. Create a free Whop account at whop.com. Use the same account for Content Rewards.
  2. Set up payouts in your Whop Balance using the withdrawal options Whop shows for your country, so you're ready before your first payout.
  3. Find clipping communities on Whop Discover. Clipping agencies (like Amplify Media below) post their campaigns, feedback channels and tips there.
  4. Track everything in one place: submissions, approvals and pending earnings show up in your Whop account.

Free to join. Before you pay for any "clipping course" or paid group on Whop, remember that you don't need one. Open campaigns are free to join.

Amplify Media

A UK clipping agency running TV, film, games, brand and music campaigns, with 1,000+ clippers.

How to join

  1. Join their free Whop community at whop.com/amplifymedia.
  2. Create an account on their clipper page and connect your Discord and TikTok.
  3. Read their beginner guide on how to clip, then introduce your niche (say "gaming") and share an edit in their Discord for feedback.
  4. Find their open campaigns on Content Rewards, read the full brief and Campaign Rules, and submit your clip links through that campaign.

Open campaigns need no paid membership. "Alpha" is an optional application for private briefs, so check any cost before applying. Only approved views are paid.

How the money works

Earnings = (views ÷ 1,000) × the campaign's rate, up to the campaign's max per clip, minus the 10% fee.

100,000 views × $1 per 1,000 = $100 → $90 after the fee

A clip also has to reach the campaign's minimum payout before it's reviewed. Ten clips at 20,000 views each pays the same as one at 200,000, so post consistently.

Option 2: pitch streamers directly

Don't want to rely on campaigns? Offer to run a streamer's short-form content for a monthly fee. Smaller and mid-size streamers who'll be playing GTA 6 are the easiest to land.

  1. Make 3 sample clips first

    Use their footage only as private samples, or footage you're allowed to use. Send the clips themselves, not a promise.

  2. Find their business contact

    Check their channel's About page, their Twitch or Kick panels, or their pinned links for a business email or Discord.

  3. Send a short, specific message

    Copy this and personalise it:

Hi [name]! I'm a short-form editor and I clipped 3 moments from your recent stream as samples: [links]. When you start GTA 6, I can turn every stream into daily Shorts, Reels and TikToks with captions, so you get more reach without the extra work. Want me to do a free week so you can see the results?

Good to know

Budgets run out. Campaigns have a fixed budget. Once it's spent, new views stop paying, even good ones. Join campaigns early and check how much budget is left.
Earnings aren't guaranteed. Only approved clips with real views get paid. Treat the rates on this page as examples; the live campaign page is what counts.
Never buy views or use bots. Campaign teams review every submission. Fake engagement gets clips rejected and accounts removed.
You don't need to own GTA 6. You're editing other people's streams, not playing. A normal laptop and one of the free tools above is enough to start.
